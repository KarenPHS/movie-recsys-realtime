MAE / RMSE 怎麼算的？

原理：每一筆使用者評分進來時，把實際評分跟 NCF 模型的預測比一下，誤差累積到一個「滑動視窗」，視窗只看最近 500 筆。

MAE = (1/N) × Σ |y_actual − y_predicted| RMSE = √[ (1/N) × Σ (y_actual − y_predicted)² ] 其中 N 是視窗大小（這裡 N = 500 筆最近的評分）

怎麼解讀：

  • MAE = 0.7 代表平均每次預測誤差 0.7 分（5 分制）
  • RMSE 比 MAE 大 是因為它對大誤差懲罰更重（平方）。差距越大，代表「偶爾預測爆炸」越嚴重
  • 狀態判定：MAE < 0.7 EXCELLENT，0.7~1.0 OK，1.0~1.3 WARNING，> 1.3 ALERT_RETRAIN

PSI 怎麼算的？

原理：把訓練資料和最近進來的評分各自切成 5 個區間（1 分 / 2 分 / ... / 5 分），算每個區間的比例，然後看「最近的分布」跟「訓練的分布」差多少。

PSI = Σ ( q_i − b_i ) × ln( q_i / b_i ) b_i = 訓練資料中分數落在第 i 區間的比例 q_i = 最近資料中分數落在第 i 區間的比例

白話舉例：訓練時 5 分占 30%，最近 5 分卻只剩 10% → 用戶突然不愛給高分了 → PSI 會跳。

判讀標準（業界通用）：

  • PSI < 0.1 = 分布穩定，不用管
  • PSI 0.1~0.2 = 有輕微偏移，繼續觀察
  • PSI > 0.2 = 顯著偏移，模型該用最新資料重訓了
