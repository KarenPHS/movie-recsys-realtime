電影推薦系統

5 台 VM 自架 Hadoop 叢集，實現自我監控的即時推薦系統

Hadoop 3.3.6 Spark 3.5.1 Kafka 3.9 HBase 2.5.8 PyTorch NCF Trino Flask

① 雙軌解耦架構：計算與服務分離

採用 Lambda Architecture，將重量級訓練任務（Spark MLlib / PyTorch）移至線下，結果寫進 HBase / HDFS；線上請求僅需毫秒級 row lookup。徹底解耦訓練與服務，確保模型更新不影響線上效能

② MLOps 監控閉環：模型自我評估

模型上線後持續被評估 ─ 每筆使用者評分進來，即時與預測值比對，計算滑動視窗的 MAE / RMSE。MAE 超標自動觸發重訓，實現模型生命週期的自動化管理

③ 前瞻資料監控：PSI 漂移預警

導入 PSI (Population Stability Index) 監控輸入特徵的分布變化（評分、時段、星期等）。在誤差爆發前先從「資料源頭」偵測漂移並告警，比起只看模型誤差更早一步發現問題

🎬

大眾推薦結果

任意使用者（1–610）的 Top-20 個人化推薦。資料來自 Spark MLlib ALS 離線訓練後寫入 HBase

NCF 即時預測 API

同樣的使用者，但這次是 PyTorch NCF 模型在請求進來時即時推理（embedding 查表 + MLP）。純 API，回傳 JSON 給程式串接

評分一部電影

評分會即時被拿去跟 NCF 模型的預測比對，更新模型監控儀表板的 MAE / RMSE；同時存進 HBase 作為下次重訓的資料
📊

模型監控儀表板★ 主打功能

即時 MAE、RMSE、各特徵 PSI Data Drift 偵測。每 60 秒自動刷新；異常時會變紅。內含計算方式說明
